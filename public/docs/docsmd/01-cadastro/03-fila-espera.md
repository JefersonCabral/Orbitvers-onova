# Passo 2: Entrar na Fila de Espera

Clique no botão **"Entrar na Fila de Espera"** para prosseguir com o cadastro.

## 📝 Instruções

1. Na página inicial de registro, localize o botão **"Entrar na Fila de Espera"**
2. Clique no botão
3. Você será direcionado para a primeira etapa do cadastro
