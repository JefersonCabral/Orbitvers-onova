# Passo 4: Etapa 2 - Dados Pessoais

Na segunda etapa, você preencherá suas informações pessoais:

![Etapa 2 - Dados Pessoais](../images/01-05-dados-pessoais.png)

## 4.1 Nome Completo

1. No campo **"Nome Completo"**, digite seu nome completo
2. Exemplo: `Usuário Tutorial OrbitSender`
3. Use o mesmo nome que você usa profissionalmente

## 4.2 Número de WhatsApp

1. No campo **"WhatsApp"**, digite seu número de WhatsApp
2. O formato deve ser: `(99) 99999-9999`
3. O sistema formata automaticamente conforme você digita
4. Exemplo: `(44) 99826-9363`

![Etapa 2 completa - Dados Pessoais preenchidos](../images/01-06-dados-pessoais-completo.png)

### ℹ️ Sobre o número de WhatsApp

O número informado aqui é apenas para **contato do suporte** com você. **NÃO será usado para fazer os disparos**. Os disparos serão feitos pelos números que você conectar posteriormente na seção de Canais (veja [Conexão de Canais](../02-canais/README.md)).

## 4.3 Prosseguir para próxima etapa

Após preencher os dados pessoais, clique em **"Próximo"** para seguir para a Etapa 3.
