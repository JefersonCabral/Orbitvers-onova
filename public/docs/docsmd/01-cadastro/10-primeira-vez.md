# Passo 9: Primeira Vez no Sistema

Após fazer login pela primeira vez, você verá o Dashboard:

![Dashboard principal do OrbitSender](../images/03-dashboard.png)

## 📋 Checklist inicial

1. ✅ Explore o menu lateral para se familiarizar com as seções
2. ✅ Verifique se consegue acessar todas as seções do menu
3. ✅ Acesse a seção "Canais" para preparar a conexão do WhatsApp: `https://app.orbitsender.com/channels` (veja [Conexão de Canais](../02-canais/README.md))
4. ✅ Acesse "Configurações" para entender as opções disponíveis: `https://app.orbitsender.com/settings` (veja [Configurações](../03-configuracoes/README.md))
5. ✅ Explore a interface para se familiarizar

## 💡 Recomendação

Recomendamos usar o sistema pelo **computador** na primeira vez, pois facilita a visualização e configuração. Após se familiarizar, você pode usar pelo celular se preferir.

## 📱 O que você encontrará no Dashboard

- **Menu Lateral:** Com todas as seções do sistema
- **Estatísticas:** Campanhas, Canais, Mensagens e Grupos (tudo zerado inicialmente)
- **Status de Conexão:** No topo direito, mostrando "Desconectado" (até conectar um canal)
- **Guia de Início Rápido:** Um card no topo com os primeiros passos
