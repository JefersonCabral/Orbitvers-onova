# Passo 3: Criar um Novo Canal

Vamos criar seu primeiro canal passo a passo:

## 3.1 Abrir o Modal de Criação

1. Clique no botão **"Criar Canal"** ou **"Novo Canal"**
2. Um modal será aberto na tela

![Modal para criar novo canal](../images/02-05-modal-criar-canal.png)

## 3.2 Preencher o Nome do Canal

1. No campo **"Nome do Canal"**, digite um nome descritivo
2. Exemplos: `Canal Principal`, `iPhone 15`, `Samsung`, `WhatsApp Empresarial`
3. O sistema formatará automaticamente o nome (removendo espaços e convertendo para minúsculas com hífens)

![Nome do canal preenchido e formatado](../images/02-06-nome-canal-preenchido.png)

### 💡 Formatação Automática

O sistema formata automaticamente o nome do canal. Por exemplo:
- Se você digitar: `Canal Principal Tutorial`
- Será formatado para: `canal-principal-tutorial`

Isso facilita a identificação e organização dos seus canais.

## 3.3 Escolher o Tipo de Conexão

Você verá duas opções de conexão:

![Opções de tipo de conexão: QR Code e Celular Virtual](../images/02-07-qr-code-selecionado.png)

### Opção 1: QR Code (Recomendado para começar)

- **Velocidade:** ⭐⭐⭐⭐⭐ (5/5)
- **Entrega:** ⭐⭐⭐⭐⭐ (5/5)
- **Estabilidade:** ⭐⭐⭐⭐⭐ (5/5)
- **Descrição:** 📱 Conecte seu número através do QR Code

### Opção 2: Celular Virtual

- **Velocidade:** ⭐⭐⭐⭐⭐ (5/5)
- **Entrega:** ⭐⭐⭐⭐⭐ (5/5)
- **Estabilidade:** ⭐⭐⭐⭐⭐ (5/5)
- **Descrição:** 📱 Conecte um novo número de WhatsApp

### ✅ Para este tutorial, vamos usar QR Code:

1. Clique na opção **"QR Code"**
2. Esta opção será destacada (selecionada)
3. O botão **"Criar"** será habilitado

## 3.4 Finalizar a Criação

1. Após preencher o nome e selecionar o tipo de conexão (QR Code), clique no botão **"Criar"**
2. Aguarde alguns segundos enquanto o canal é criado
3. O modal será fechado e você verá o canal criado na lista

![Canal criado com sucesso](../images/02-08-qr-code-gerado.png)

## ✅ Canal Criado!

Após criar, você verá:

- Nome do canal (formatado)
- Tipo de conexão (QR Code)
- Status: **"Pendente"** (ainda não conectado)
- Token do canal
- Data de criação
- Botões de ação: **"Novo QR Code"**, **"Editar"**, **"Excluir"**
