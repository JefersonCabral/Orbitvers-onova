# Problemas Comuns

## ❓ Problemas ao Criar Canal

Se você encontrar problemas ao criar um canal, verifique:

- **Nome do canal vazio:** Preencha o campo "Nome do Canal"
- **Tipo de conexão não selecionado:** Clique em uma das opções (QR Code ou Celular Virtual)
- **Está no celular:** Desça a página para encontrar o botão, ou acesse pelo computador (recomendado)

## ❓ QR Code não está sendo lido

Se o QR Code não estiver sendo lido:

1. Feche completamente o aplicativo WhatsApp
2. Abra novamente o WhatsApp
3. Feche a tela de QR Code no sistema
4. Clique em "Novo QR Code" novamente
5. Tente escanear novamente

💡 **Dica:** Use um dispositivo diferente para escanear o QR Code se o problema persistir.

## ❓ Mensagem de "sem internet" mesmo com internet funcionando

Se aparecer a mensagem de "sem internet" mesmo com internet funcionando:

1. Reinicie o aparelho celular
2. Desconecte e reconecte o canal no sistema
3. Crie um novo canal se o problema persistir

💡 Isso geralmente é um bug temporário do WhatsApp, não do sistema.

## 🔄 Desconexão e Reconexão

Se seu canal desconectar (status mudar para "Inativo"), siga estes passos para reconectar:

### ⚠️ Desconexão Automática

Por medidas de segurança durante os testes, as conexões podem ser desconectadas automaticamente após um período. Se isso acontecer, não se preocupe - é normal e fácil de resolver.

### Como Reconectar:

1. Acesse a página de **Canais** (`https://app.orbitsender.com/channels`)
2. Localize o canal desconectado na lista
3. Clique no botão **"Novo QR Code"**
4. Siga o mesmo processo de escanear o QR Code novamente
5. Aguarde o status mudar para **"Ativo"**

💡 **Dica:** Você pode usar o mesmo número do WhatsApp para reconectar. Não é necessário criar um novo canal.

## 📱 Múltiplos Canais

Você pode conectar vários números ao mesmo tempo para aumentar a capacidade de disparo:

### Como Criar Múltiplos Canais:

1. Crie um novo canal para cada número (siga o mesmo processo)
2. Dê nomes diferentes para cada canal para facilitar a identificação
3. Conecte cada um via QR Code separadamente
4. Todos aparecerão na lista de canais

### Vantagens de Usar Múltiplos Canais:

- **Maior velocidade:** Mais canais = mais mensagens enviadas simultaneamente
- **Distribuição automática:** Quando você usa múltiplos canais no mesmo segmento, o sistema distribui os grupos de forma igualitária entre eles
- **Redundância:** Se um canal desconectar, os outros continuam funcionando
- **Flexibilidade:** Você pode usar canais diferentes para diferentes tipos de mensagens ou segmentos

⚠️ **Dica Importante:** Cada canal deve usar um número de WhatsApp diferente. Você não pode conectar o mesmo número em múltiplos canais simultaneamente.
