## 🎯 Objetivo

Este tutorial vai te guiar através do processo completo de criar e conectar um canal do WhatsApp ao sistema OrbitSender, desde o acesso inicial até a confirmação de conexão.

## 📋 Pré-requisitos

Antes de começar, certifique-se de ter:

- ✅ Conta criada e liberada pelo suporte
- ✅ Ter feito login no sistema
- ✅ WhatsApp instalado no celular que deseja conectar
- ✅ Celular com câmera funcional para escanear QR Code
