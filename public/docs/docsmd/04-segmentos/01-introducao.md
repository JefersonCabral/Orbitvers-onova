# Introdução

Os segmentos são uma forma de organizar grupos do WhatsApp de maneira eficiente.

## Por que criar segmentos?

- **Organização:** Agrupe grupos relacionados em um único segmento
- **Facilidade:** Envie mensagens para vários grupos de uma vez
- **Eficiência:** Gerencie melhor seus grupos e campanhas
- **Flexibilidade:** Crie diferentes segmentos para diferentes tipos de campanhas

- Como acessar a página de segmentos
- Como selecionar um canal
- Como sincronizar e filtrar grupos
- Como criar um segmento
- Como gerenciar seus segmentos
