# Passo 1: Acessar a Página de Segmentos

Para criar um novo segmento:

## 📝 Instruções

### 1.1 Navegar até Segmentos

1. No menu lateral esquerdo, localize a opção **"Segmentos"** e clique nela
2. Ou acesse diretamente em: `https://app.orbitsender.com/segments`
3. Você será direcionado para a página de segmentos

![Página inicial de segmentos do OrbitSender](../images/04-01-segmentos-inicial.png)

### 1.2 Iniciar Criação

1. Na página de segmentos, localize o botão **"Novo Segmento"** (geralmente no canto superior direito)
2. Clique no botão para iniciar o processo de criação
3. Você será direcionado para o assistente de criação de segmentos

![Assistente de criação de segmentos - Passo 1](../images/04-02-criar-segmento-step1.png)
