# Passo 1: Acessar o Quick Sender

## 📝 Instruções

1. No menu lateral, clique em **"Quick Sender"**
2. Ou acesse diretamente em: `https://app.orbitsender.com/quick-sender`
3. Você verá uma interface similar a um chat com uma mensagem de boas-vindas
4. Na parte inferior, você encontrará os campos para adicionar imagem e texto

![Tela inicial do Quick Sender](../images/05-01-quick-sender-inicial.png)

## 📋 O que você verá

A tela inicial mostra:

- Uma mensagem de boas-vindas: "Bem vindo ao quick sender. Me mande uma imagem e um texto para começar."
- Botão "Adicionar arquivo" para upload de imagens
- Botão "Adicionar emoji" para incluir emojis na mensagem
- Campo de texto para digitar sua mensagem
- Botão "Enviar" para criar a campanha
