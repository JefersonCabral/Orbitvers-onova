# Passo 2: Preencher Mensagem

## 📝 Instruções

1. No campo de texto, digite a mensagem que deseja enviar
2. Você pode usar emojis clicando no botão "Adicionar emoji"
3. Exemplo de mensagem: "Olá! Esta é uma mensagem de teste do OrbitSender."

![Mensagem preenchida](../images/05-02-mensagem-preenchida.png)

## 💡 Dica

Seja claro e objetivo na mensagem. Lembre-se que você está enviando para grupos do WhatsApp.
