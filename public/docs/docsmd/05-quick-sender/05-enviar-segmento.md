# Passo 4: Enviar e Selecionar Segmento

Após preencher a mensagem e adicionar a imagem (se desejar), você pode enviar.

## 📝 Instruções

1. Clique no botão **"Enviar"** após preencher a mensagem
2. Uma seção "Selecionar Segmento" aparecerá com os segmentos disponíveis
3. Selecione o segmento para o qual deseja enviar a mensagem

![Selecionar segmento](../images/05-04-selecionar-segmento.png)

![Segmento selecionado](../images/05-05-segmento-selecionado.png)

## ⚠️ Importante

**💡 Não tem segmentos?**

Se você ainda não criou um segmento, veja o tutorial sobre [Criação de Segmentos](../04-segmentos/README.md) antes de continuar.
