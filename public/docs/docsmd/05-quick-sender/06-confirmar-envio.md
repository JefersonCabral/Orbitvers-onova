# Passo 5: Confirmar Envio

Após selecionar o segmento, você precisa confirmar o envio.

## 📝 Instruções

1. Após selecionar o segmento, você verá uma mensagem de confirmação
2. Clique em **"Sim, enviar"** para confirmar
3. Aguarde o processamento

## ✅ Campanha Enviada

Após confirmar, a campanha será criada e entrará na fila de processamento. O sistema retornará à tela inicial do Quick Sender, permitindo que você crie uma nova mensagem se desejar.
