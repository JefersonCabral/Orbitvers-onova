# Passo 6: Verificar Campanha na Lista

Após criar a campanha pelo Quick Sender, você pode acompanhá-la na página de Campanhas (`https://app.orbitsender.com/campaigns`):

## 📝 Instruções

1. No menu lateral, clique em **"Campanhas"**
2. Ou acesse diretamente em: `https://app.orbitsender.com/campaigns`
3. Você verá a campanha recém-criada listada
4. A campanha terá o nome "Quick Campaign" seguido da data e hora de criação
