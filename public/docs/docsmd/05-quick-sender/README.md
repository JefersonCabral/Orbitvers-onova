## 🎯 Objetivo

Aprender a fazer seu primeiro disparo usando o Quick Sender de forma rápida e intuitiva.

## 📋 Pré-requisitos

Antes de começar, certifique-se de ter:

- ✅ Conta criada e liberada
- ✅ Login realizado
- ✅ Pelo menos um canal conectado (veja [Conexão de Canais](../02-canais/README.md))
- ✅ Pelo menos um segmento criado (veja [Criação de Segmentos](../04-segmentos/README.md))
