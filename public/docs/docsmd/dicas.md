# 💡 Dicas Importantes

## ✅ Boas Práticas

- Use intervalos maiores entre mensagens para maior segurança
- Comece com configurações conservadoras e vá ajustando
- Mantenha seus números aquecidos antes de disparar
- Monitore regularmente o status de suas campanhas

## ⚠️ Prevenção de Banimento

### Intervalos Recomendados

- **Intervalo Mínimo:** 10 segundos (recomendado)
- **Intervalo Máximo:** 15-20 segundos
- **Mensagens por Ciclo:** 2-3 mensagens
- Não dispare muito rápido no início
- Evite disparar durante a madrugada

## ℹ️ Informações Importantes

- O sistema faz troca automática de IP para maior segurança
- Conexões via QR Code podem precisar ser renovadas a cada 48h
- Você pode usar múltiplos canais simultaneamente
- Campanhas são processadas em fila automaticamente
