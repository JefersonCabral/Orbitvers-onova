# 🔧 Problemas Comuns e Soluções

## ❓ QR Code não está sendo lido

**Solução:**

1. Feche completamente o aplicativo WhatsApp
2. Abra novamente o WhatsApp
3. Feche a tela de QR Code no sistema
4. Clique em "Novo QR Code" novamente
5. Tente escanear novamente

💡 **Dica:** Use um dispositivo diferente para escanear o QR Code se o problema persistir.

## ❓ Mensagem de "sem internet" mesmo com internet funcionando

**Solução:**

1. Reinicie o aparelho celular
2. Desconecte e reconecte o canal no sistema
3. Crie um novo canal se o problema persistir

💡 Isso geralmente é um bug temporário do WhatsApp, não do sistema.

## ❓ Campanha ficou pendente e não está enviando

**Solução:**

1. Cancele a campanha pendente
2. Verifique se os canais estão conectados (status: Ativo)
3. Verifique se o segmento possui grupos selecionados
4. Crie uma nova campanha

💡 Se o problema persistir, entre em contato com o suporte.

## ❓ Erro ao enviar imagem

**Solução:**

O sistema aceita apenas os seguintes formatos de imagem:

- **PNG**
- **JPG**
- **JPEG**

Se você estiver usando outro formato (WEBP, GIF animado, etc.), converta para um dos formatos suportados.

## ❓ Botão não aparece na versão mobile

**Solução:**

Para algumas funcionalidades, recomendamos o uso pelo computador:

1. Acesse pelo navegador do computador para criar canais
2. Use o celular apenas para monitorar campanhas
3. Tente rotacionar a tela (modo paisagem) se necessário

💡 O sistema funciona melhor em telas maiores para configurações iniciais.

## ❓ Conexão desconectou após 48 horas

**Isso é normal!**

Por medidas de segurança durante os testes, as conexões são desconectadas automaticamente a cada 48 horas.

**Para reconectar:**

1. Acesse a página de Canais (`https://app.orbitsender.com/channels`)
2. Clique em "Novo QR Code" no canal desconectado
3. Escanee o QR Code novamente com o WhatsApp

💡 Esta é uma configuração temporária e será alterada em breve.
